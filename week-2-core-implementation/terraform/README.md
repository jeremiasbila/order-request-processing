# Week 2 Terraform learning snapshot

Week 2 focuses on the core resources: API Gateway, producer Lambda, SQS, consumer Lambda and IAM. For a single deployable source of truth and to avoid maintaining conflicting partial stacks, the fully integrated Terraform configuration is delivered in `../../week-4-production-readiness/terraform/`.

At this stage students should be able to identify the resource objects and dependencies before the Week 3 reliability and Week 4 networking additions.
